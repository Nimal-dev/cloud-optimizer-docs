The dashboard runs on your computer

This online version shows the project and the Learn section. Analysing CSV files needs the Python backend with the trained AI models, so the dashboard works when you run the project locally (no internet needed).

see HOW_TO_RUN.md in the project

cd backend && venv\Scripts\activate && uvicorn app.main:app --port 8000

cd frontend && npm run build && npm run start → http://localhost:3000
